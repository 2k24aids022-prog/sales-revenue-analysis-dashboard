# Sales Revenue & Analysis Dashboard

## Project Overview
This project showcases an interactive Sales Revenue & Analysis Dashboard developed in Power BI. The dashboard provides a comprehensive view of sales performance, revenue trends, profit analysis, and regional insights to support data-driven business decisions.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV Dataset

## Dashboard Preview
![Sales Dashboard](dashboard.png)

## Key Insights
- Analyzed overall sales revenue and profit performance.
- Identified top-performing products and sales regions.
- Tracked monthly sales trends and business growth patterns.
- Compared revenue across different categories and segments.
- Enabled interactive exploration of sales data through filters and visualizations.

## Dataset
The dataset used for this analysis is included in this repository for reference and learning purposes.
